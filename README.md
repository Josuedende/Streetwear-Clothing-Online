# Streetwear Clothing Online

A React and TypeScript streetwear storefront prototype built with Vite.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

Install the project dependencies, then start the Vite development server:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (by default, `http://localhost:5173`).

## Production build

```sh
npm run build
npm run preview
```

The storefront UI is in `App.tsx`, with its management interface in
`ControlCenter.tsx`. Global styles are in `index.css`.
